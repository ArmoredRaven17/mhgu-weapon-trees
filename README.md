# MHGU Weapon Trees

An interactive, in-browser map of every weapon upgrade tree in **Monster
Hunter Generations Ultimate** — all 14 non-Palico classes, drawn as a
flat, tilted map you pan and zoom across rather than a static diagram.

Live: https://armoredraven17.github.io/mhgu-weapon-trees/

Pick a class from the bottom bar, click any node for its full stats —
attack, affinity, slots, element, and whatever the class carries beyond
that: charge levels and coatings for Bow, ammo/rapid-fire/internal for the
Bowguns (siege ammo too, for Heavy Bowgun), phials for Switch Axe and
Charge Blade, notes for Hunting Horn, shelling for Gunlance, sharpness
bars for every Blademaster weapon, kinsect name and type for Insect
Glaive.

A weapon that branches mid-upgrade stays open past the level it unlocks —
matching the actual game mechanic, which the source database does not
record directly (see [NOTICE.md](NOTICE.md) for how that's derived).

## How it fits the family

This is a single self-contained `docs/index.html` — no build step, no
dependencies, deployed to GitHub Pages on push to `master`. Its weapon
data and several visual assets are embedded at build time from sibling
repos rather than fetched at runtime:

- **[Collection Tracker](https://github.com/ArmoredRaven17/mhgu-collection-tracker)**
  — weapon stats, materials, catalog, rarity icons, sharpness colours.
- **[mhgu-editor](https://github.com/ArmoredRaven17/mhgu-editor)** —
  coating and Hunting Horn note icons.
- **MHGU Quest Randomizer** — the MHFU font, background textures, theme
  picker, and monster icons.
- **MHFU Look Up** — the reload/recoil/deviation and shot-colour rules.

Full provenance and licensing for all of this is in
[NOTICE.md](NOTICE.md).

## Local development

```
python -m http.server 8131 --directory docs
```

There's no build script — `docs/index.html` is the deliverable. It's
regenerated by hand from the source data whenever a new class or feature
is added, not produced by a checked-in pipeline (yet).

## Status

Everything except Palico weapons is embedded. Known gaps:

- Heavy Bowgun's siege ammo colours only the types this project could
  verify against a real source; the rest render as plain text rather than
  a guessed colour (see NOTICE.md).
- A run/"challenge" mode — track what you've actually built, not just
  browse — is wired up in the code but hidden pending the rules for it
  being finalized.
